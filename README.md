# حصن المسلم اليومي | Daily Fortress of the Muslim

موقع ثابت (ملف واحد `index.html` يعمل دون سيرفر) لأذكار الصباح والمساء والأدعية وورد المحاسبة.

## المزايا
- أذكار الصباح والمساء موثقة بمصادرها ودرجة صحتها.
- مسبحة لكل ذكر متكرر مع حفظ التقدم.
- تلاوة الآيات القرآنية بصوت الشيخ محمود خليل الحصري (المصحف المرتل)، مع رجوع تلقائي للنطق الآلي عند انقطاع الإنترنت.
- بدء القراءة الصوتية من أي بطاقة (زر: القراءة من هنا).
- الوضع الليلي/النهاري، تكبير وتصغير الخط (Times New Roman)، وواجهة عربية/إنجليزية.
- قسم القرآن والتفاسير بروابط عربية وإنجليزية.

## النشر على GitHub Pages
1. ارفع ملف `index.html` (وهذا الملف) إلى مستودع جديد.
2. من صفحة المستودع: Settings ← Pages ← Deploy from a branch ← اختر `main` و `/(root)` ثم Save.
3. سيظهر رابط الموقع خلال دقيقة أو دقيقتين.

## التشغيل محليا
افتح `index.html` في المتصفح مباشرة (كروم أو إيدج للحصول على القراءة الصوتية).
